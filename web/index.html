使い方

      

        
初めての準備
Mac と Windows の導入手順、ターミナルの開き方、権限設定はガイドをご覧ください。コマンドはガイドからコピーできます。
初期設定ガイドを開く ↗

        
録音して文字にする
「マイクをオン」を押し、発言の始めと終わりに F2 を押します。長押し方式も設定で選べます。

        
辞書
画面上部の「会議情報」から、参加国・用語・背景を登録できます。

        
終了と削除
使い終わったら、録音を止めて画面上部の「終了」を押します。削除方法はガイドにあります。
