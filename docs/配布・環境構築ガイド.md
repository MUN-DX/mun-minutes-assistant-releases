# はじめて使う方へ：インストールと使い方

このアプリは、録音した音声を自分の PC で文字にします。初回だけインターネットを使って、必要なプログラムとモデルを用意します。

**現在は試用版です。** Mac の基本動作は確認済みですが、ここに載せた手順を何も入っていない Mac で最初から最後まで検証したわけではありません。Windows の起動や F2 も実機未検証です。途中で表示が違う場合は、無理に先へ進まず、エラー全文を開発者に伝えてください。

## はじめに

- インストールには数 GB 以上の空き容量が必要です。選ぶモデルによって増えます。
- モデルの取得にはインターネット接続が必要です。取得後の文字起こしと整文はローカルで行います。
- 手順中のコマンドは、GitHub のコード枠の右上にある**コピー**ボタンを使えます。コピー後、ターミナルに貼り付けて Enter キーを押してください。
- 先頭に表示される `$` や `>` は入力しません。コマンドを実行する前に、公式サイトの URL であることを確認してください。
- 配布先は公開リポジトリです。公開済みの配布版は、GitHubアカウントへの招待なしで取得できます。
- 初回の配布対象はMac（Apple Silicon）です。Windowsの説明は参考手順で、実機検証は完了していません。

## アプリをダウンロードする

1. [配布版のReleases](https://github.com/MUN-DX/mun-minutes-assistant-releases/releases)を開きます。
2. 対象バージョンの **Assets** から **mun-minutes-mac-v…zip** を選びます。
3. ダウンロードした ZIP を展開します。
4. 中に `web_app.py`、`run_mac.command`、`VERSION` が見えるフォルダを確認します。以下ではこれを「アプリのフォルダ」と呼びます。ZIP ファイルの中のまま実行しないでください。

## Mac：初回セットアップ

### 1. ターミナルを開く

1. キーボードの **⌘ Command + Space** を押します。
2. `ターミナル` と入力し、表示された「ターミナル」を開きます。
3. コピーしたコマンドをターミナルに貼り付けるときは **⌘ Command + V**、実行は **Return** キーです。

### 2. Python と開発ツールを確認する

次をコピーして実行します。

```sh
python3 --version
```

`Python 3.9` 以上が表示されれば進めます。インストールを求める画面が出た場合は、Apple の案内に従って開発ツールを導入し、完了後にもう一度実行します。うまくいかない場合は [Python 公式サイト](https://www.python.org/downloads/macos/)から Python 3 を導入してください。

### 3. Homebrew を用意する

次で確認します。

```sh
brew --version
```

バージョンが表示された方は次の「4」へ進みます。`command not found` と出る方は、[Homebrew 公式サイト](https://brew.sh/ja/)で以下と同じインストールコマンドが掲載されていることを確認し、コピーして実行します。公式のスクリプトをダウンロードして実行するコマンドです。

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

管理者パスワードを求められることがあります。**入力中は文字が表示されません**が、入力後に Return を押します。

インストール完了時に表示される **Next steps** の案内に従ってください。`brew --version` で確認できない場合は、次のいずれかを実行した後、もう一度確認します。

Apple Silicon（M1・M2・M3 など）の Mac：

```sh
eval "$(/opt/homebrew/bin/brew shellenv)"
```

Intel の Mac：

```sh
eval "$(/usr/local/bin/brew shellenv)"
```

### 4. 音声処理の部品をインストールする

```sh
brew install ffmpeg whisper.cpp
```

終わったら、次をそれぞれ実行し、実行ファイルの場所が表示されることを確認します。

```sh
command -v ffmpeg
```

```sh
command -v whisper-cli
```

### 5. Ollama をインストールする

1. [Ollama 公式サイト](https://ollama.com/download)から Mac 用をダウンロードします。
2. 開いた画面の案内に沿ってインストールし、Ollama を起動します。
3. 整文モデルは後でアプリ画面からダウンロードします。

### 6. アプリを起動する

Finder でアプリのフォルダを開き、`run_mac.command` をダブルクリックします。

うまく開けないときは、ターミナルに `cd` と半角スペースを入力し、アプリのフォルダを Finder からターミナルへドラッグして Return を押します。フォルダの場所が自動で入力されます。その後、次を実行します。

```sh
python3 web_app.py
```

Chrome が自動で開かない場合は、アドレス欄に次を入力してください。

```text
http://127.0.0.1:8000/
```

使い終わったら、アプリ画面右上の **終了** を押してください。録音中は先に「録音停止」を押し、処理完了を待ちます。タブを閉じるだけでは裏側は終了しません。ターミナルで **Control + C** を押して終了することもできます。

### 7. マイクと F2 の権限を許可する

- Chrome のマイク許可が表示されたら「許可」を選びます。表示されない場合は、Chrome のアドレス欄左側のアイコンからサイト設定を開き、マイクを許可します。
- Mac の **システム設定 → プライバシーとセキュリティ → マイク** でも Chrome が許可されていることを確認します。
- Google Docs を開いているときも F2 を使う場合、**システム設定 → プライバシーとセキュリティ → アクセシビリティ**で、アプリを起動したターミナルや Python 実行プロセスへの許可が必要になる場合があります。OS に表示された対象を確認し、許可後はアプリを再起動します。

## Windows：初回セットアップ（実機未検証）

以下は Windows 10/11 の 64 ビット PC を想定した手順です。表示や性能は PC によって異なります。

### 1. PowerShell を開く

1. 画面下の **スタート**を押し、`PowerShell` と入力します。
2. **Windows PowerShell** を開きます。通常は管理者として起動する必要はありません。
3. コマンドを貼り付けるときは **Ctrl + V**、実行は **Enter** キーです。

### 2. Python を用意する

次を実行します。

```powershell
py -3 --version
```

`Python 3.9` 以上が表示されれば進めます。見つからない場合は、[Python 公式サイト](https://www.python.org/downloads/windows/)から Python 3 を入手してインストールします。インストーラーに **Add python.exe to PATH** が表示された場合はチェックを入れます。

導入後は PowerShell を一度閉じて開き直し、上のコマンドをもう一度実行してください。

### 3. FFmpeg を用意する

次を実行します。`winget` が確認を求めたら表示を読んで進めてください。

```powershell
winget install --id Gyan.FFmpeg --exact --source winget
```

完了したら PowerShell を閉じて開き直し、次で確認します。

```powershell
ffmpeg -version
```

`winget` が見つからない場合や組織の PC で導入が制限されている場合は、管理者に確認してください。別の方法は [FFmpeg の公式ダウンロード案内](https://ffmpeg.org/download.html)を参照してください。

### 4. Ollama を用意する

[Ollama 公式サイト](https://ollama.com/download/windows)から Windows 用インストーラーをダウンロードして開き、画面の指示に従います。完了後、Ollama を起動します。

### 5. 音声認識プログラムを用意する

まず、PowerShell に `cd` と半角スペースを入力し、エクスプローラーで開いた**アプリのフォルダ**を PowerShell にドラッグして Enter を押します。`web_app.py` があるフォルダに移動します。

次のコマンドを**上から順番に１つずつ**実行します。公式の whisper.cpp v1.8.3 の Windows x64 版をダウンロードし、内容を確認してから、アプリのフォルダ内に配置します。

```powershell
New-Item -ItemType Directory -Force -Path '.runtime\bin' | Out-Null
```

```powershell
$whisperZip = Join-Path $env:TEMP 'mun-whisper-v1.8.3-x64.zip'
```

```powershell
Invoke-WebRequest -Uri 'https://github.com/ggml-org/whisper.cpp/releases/download/v1.8.3/whisper-bin-x64.zip' -OutFile $whisperZip
```

次の結果が `True` と表示された場合だけ、次に進んでください。`False` やエラーの場合は展開・実行せず、開発者に知らせてください。

```powershell
(Get-FileHash -Algorithm SHA256 $whisperZip).Hash -eq 'd824b1e37599f882b396e73f1ee0bfd5d0529f700314c48311dcbd00b803321d'
```

```powershell
Expand-Archive -LiteralPath $whisperZip -DestinationPath '.runtime\whisper-v1.8.3' -Force
```

```powershell
Copy-Item '.runtime\whisper-v1.8.3\Release\*' '.runtime\bin\' -Force
```

`whisper-cli.exe` だけでなく、同じフォルダに入っている DLL も必要です。上のコピー操作では両方を配置します。

### 6. アプリを起動する

アプリのフォルダ内の `start_win.bat` をダブルクリックします。Chrome が開かない場合は、アドレス欄に次を入力します。

```text
http://127.0.0.1:8000/
```

終了するときは、録音と文字化を終えてからアプリ画面右上の **終了** を押します。起動した黒い画面で **Ctrl + C** を押す方法もあります。タブを閉じるだけでは裏側は終了しません。Windows のマイク設定と Chrome のマイク許可も確認してください。Windows での F2 連携は実機未検証です。

## 画面でモデルを選ぶ

1. 画面上部の **設定** を開き、「使い始める準備」の状態を確認します。
2. 保存先を変更したい場合は、音声認識モデル・議事録のフォルダを入力して「保存先を変更」を押します。既存ファイルは移動されません。整文モデルは Ollama の保存先を使います。
3. 「モデルを追加」で音声認識モデルを選び、「ダウンロード」を押して完了を待ちます。新規利用時の標準は Large-v3-Turbo FP16（約1.62 GB）です。
4. 文章を整えるモデルも選んでダウンロードします。標準は Qwen3 4B です。「Qwen3.5 4B 日本語向け」も選べます。Ollama が起動している必要があります。
5. 下にある各モデルの「切り替え」で、ダウンロードしたモデルを選びます。

モデルの取得中はインターネット接続が必要です。通信が途切れた場合は自動で最大3回再試行します。それでも失敗した場合は接続と空き容量を確認し、もう一度「ダウンロード」を押してください。対応するモデルでは、取得済みの部分から再開し、最後にファイル全体を検証します。中止した場合も、対応するモデルの途中データは保存先に残し、次回の再開に使います。サイズが大きいモデルほど、時間や保存容量が必要です。

## 録音・辞書・共有

- **音声の準備**：画面上部の「設定」→「音声入力」でマイクを選びます。「3秒テスト録音」を押し、録音が終わったら再生ボタンで聞きます。録音中は、画面上部の「入力」メーターで音が入っているか確認できます。
- **マイク**：「マイクをオン」を押します。発言が始まったら F2 を１回押し、終わったらもう１回押します。「設定」で長押し方式にも変更できます。
- **仕上げ**：「設定」→「発言の処理」で、発言中から下書きを表示するか、発言終了後に処理を始めるか選べます。「仕上げ中」の間も次の発言を録音できます。「原文を確認」と表示された場合は、整文を見送った可能性があるため内容を確認してください。音声の誤認や数字・否定の誤りが残る場合があります。
- **完成版の確認**：編集中やコピー後に別の完成版が届いた場合は「完成版を確認」で現在の文章と見比べ、使う方を選べます。処理に失敗した場合は「再試行」を使えます。
- **音声の聞き直し**：「設定」→「発言の処理」で発言音声を「保存して聞き直す」に変更しておくと、処理後に各発言の「音声」から再生できます。保存日数が `0` の場合は自動削除されません。日数を指定した場合は、新しい音声を保存するときに期限を過ぎた音声が削除されます。不要な音声は再生欄の「音声を削除」で削除することもできます。
- **コピー**：発言の右端の「コピー」を押し、Google Docs に貼り付けます。
- **参加国**：「会議情報」→「参加国」に国名を入力し、「指示文をコピー」を押します。外部 AI の回答を同じ画面に貼り、確認して登録します。登録済みの参加国は手動でも編集できます。
- **本会議辞書**：「会議情報」→「本会議辞書を作る」で指示文をコピーし、BG と一緒に外部 AI に渡します。返ってきた JSON テキストを貼り付け、「内容を確認」を押します。件数を確認してから「〇件を登録する」を押すと、本会議辞書に保存されます。登録した用語は「登録済みの用語辞書」の「本会議辞書」で確認できます。
- **会議の背景**：「会議情報」→「会議の背景を作る」で専用の指示文をコピーし、BG と一緒に外部 AI に渡します。回答を貼り付け、内容を確認して登録します。背景は同じ画面で削除できます。BG を外部 AI に渡すと、そのサービスに資料が送られます。
- **会議の切り替え**：再読み込みや再起動の後も、同じブラウザでは前回の会議を開きます。別の会議を始めるときは「会議情報」→「新しい会議」を押します。過去の会議は「履歴」から開けます。
- **共通辞書**：「会議情報」→「登録済みの用語辞書」で共通辞書と本会議辞書を確認し、個別に用語を追加できます。
- **２台で使う**：録音担当の画面で「共有」→「共有を開始」を押し、表示された URL と接続コードをコピー担当に伝えます。同じネットワークを使用してください。現在の共有通信は暗号化されないため、信頼できるネットワークで使ってください。

## セキュリティ画面やエラーが出たとき

- **Mac がアプリを開けない**：未署名・未公証のファイルは macOS が警告する場合があります。ダウンロード元とファイルの信頼性を確認できる場合は、一度開こうとした後、**システム設定 → プライバシーとセキュリティ**の下部に表示される「このまま開く」を選び、確認画面の指示に従う方法があります。選択肢が出ない場合もあります。詳しくは [Apple の公式案内](https://support.apple.com/ja-jp/102445)を参照し、信頼性を確認できないファイルは実行しないでください。
- **Windows の SmartScreen が警告する**：ダウンロード元と発行元を確認し、信頼できるファイルと判断できる場合に限り、画面に「詳細情報」→「実行」が表示されていれば選ぶ方法があります。組織の PC では実行を選べない場合があり、そのときは管理者に相談してください。詳しくは [Microsoft の案内](https://learn.microsoft.com/ja-jp/windows/apps/package-and-deploy/smartscreen-reputation)を参照してください。
- **共有時にファイアウォールの確認が出る**：接続先とネットワークを確認し、使用しているプライベートネットワークで許可できるか確認します。セキュリティ機能全体を無効にする必要はありません。
- **「コマンドが見つかりません」**：インストール後にターミナルを閉じて開き直し、確認コマンドを再実行してください。
- **画面が開かない／接続できない**：起動したターミナルを閉じていないか確認し、`http://127.0.0.1:8000/` を開いてください。別ポートで起動した場合は、その画面に表示された URL を使います。
- **Ollama 未接続**：Ollama アプリが起動しているか確認してください。
- **共有に参加できない**：同じネットワークか、録音担当側で共有がオンか、URL とコードが正しいか確認してください。会場のネットワークでは端末間接続が制限されている場合があります。

セキュリティ保護を一括で無効化したり、内容を確認できないコマンドを実行したりしないでください。

## アップデートする

新しいZIPは既存フォルダに上書きせず、別のフォルダへ展開してください。先にアプリを終了し、設定画面で使っていた保存先と「議事録データ」「モデル」「辞書」を確認してバックアップします。新しい版を起動したら、以前と同じ保存先・モデルを設定し、履歴と辞書を確認してから使用してください。設定ファイルや共通辞書を新しい版へ移す場合も、元ファイルを残してください。

## アンインストール（アプリを使わなくなったとき）

1. 画面右上の **終了** を押し、アプリを終了します。
2. 設定画面で変更した保存先も確認してください。アプリのフォルダ内の「議事録データ」「モデル」「辞書」や、別の場所に保存したファイルは、必要なら **書類** や外付けドライブにコピーします。コピー先で開けることを確認してください。
3. アプリのフォルダにある **`uninstall_mac.command`**（Mac）または **`uninstall_windows.bat`**（Windows）を開きます。確認画面で `Y` と入力して Enter を押すと、アプリ内の実行用ファイルだけを削除します。キャンセルする場合は `Y` 以外を入力します。
4. 議事録やモデルが必要な場所に残っていることを確認したら、アプリのフォルダを Finder やエクスプローラーでゴミ箱に移します。フォルダ内に残したデータも一緒に削除されるので注意してください。

この操作では、別の場所に指定したデータ、Ollama 本体、Ollama が管理するモデル、Homebrew、FFmpeg、Python は削除しません。他のアプリも使う可能性があるためです。それらも削除したい場合は、各ソフトの公式の削除方法をご確認ください。Windows では、実行中の Python を含むフォルダは自動削除できず残る場合があります。
