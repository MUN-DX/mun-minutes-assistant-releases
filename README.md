# 模擬国連 議事録支援

会場の発言をマイクから取り込み、PC内で文字起こし・整文する試用版です。Chromeで操作し、発言の前後でF2を押して記録します。

## ダウンロードと使い始め方

配布版と更新情報は **[Releases](https://github.com/MUN-DX/mun-minutes-assistant-releases/releases)** を確認してください。初回はMac向けβ版です。Releaseの「Assets」にある `mun-minutes-mac-v…zip` をダウンロードして展開します。

**[インストール・使い方ガイド](docs/配布・環境構築ガイド.md)** に、必要な準備とコピーして使えるコマンドをまとめています。

このZIPにはPython本体、FFmpeg、whisper.cpp、Ollama、モデルは含みません。初回にそれぞれを導入し、アプリの設定画面でモデルを取得します。モデルの取得には数GBの通信と保存領域が必要です。

1. 導入ガイドに従い、Python・FFmpeg・whisper.cpp・Ollamaを準備します。
2. Ollamaを起動し、展開したフォルダの `run_mac.command` を開きます。
3. Chromeで `http://127.0.0.1:8000/` を開き、「設定」でモデルを取得・選択します。
4. 「マイクをオン」を押し、ブラウザとMacのマイク許可を確認します。
5. 発言の前後でF2を押します。文字起こし・整文結果を確認してコピーし、議事録へ貼り付けます。
6. 終了するときは、録音・処理を終えて画面右上の「終了」を押します。

## 対応と確認状況

- 初回の配布対象はMac（Apple Silicon）です。確認環境はmacOS 27.2、Python 3.14.4、Chrome、Whisper Large-v3-Turbo、Qwen3 4Bです。
- 合成日本語音声から文字起こし・整文・保存までの動作を確認しています。文字起こし・整文には誤認や意味の変化があり得るため、人が原文と音声を確認してください。
- 何も入っていないMacでの初回導入、実会場の音声、長時間運用、Intel Macは未検証です。
- Windows向けファイルと参考手順も含みますが、Windowsの実機動作は未検証で、今回の配布対象には含めていません。
- 署名・公証済みのネイティブアプリや、すべてを同梱したインストーラーではありません。

## 保存と共有

標準では、展開したフォルダ内の「議事録データ」「モデル」「辞書」に保存します。保存先は設定画面で変更できます。アプリを更新するときは、新しいZIPを別のフォルダに展開し、既存データをバックアップしてから、以前の保存先を設定してください。既存フォルダへの上書き展開は避けてください。

モデル取得・更新時などを除き、文字起こしと整文は端末内で行います。議事録、録音、利用者の辞書・設定、モデルは配布ZIPに含みません。

共有を有効にすると、同じネットワークの端末と文章を共有できます。現在の共有通信は暗号化されないため、信頼できるネットワークで使用してください。

## ライセンスと外部ソフトウェア

アプリ本体のオープンソースライセンスは、現時点では設定していません。同梱する国コードデータの出典・ライセンスと、別途導入する部品は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) に記載しています。
